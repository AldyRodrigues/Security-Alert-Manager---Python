# Security-Alert-Manager---Python
Projeto desenvolvido em Python com o objetivo de praticar conceitos fundamentais de programação através da criação de um sistema de gerenciamento de alertas de segurança.

## Funcionalidades
- Cadastro de alertas.
- Armazenamento de informações utilizando dicionários.
- Exibição dos alertas cadastrados.
- Filtragem por prioridade.
- Tratamento básico de entradas inválidas.

## Conceitos aplicados
- Funções e parâmetros.
- Estruturas condicionais.
- Laços de repetição.
- Dicionários.
- Manipulação de strings.
- Tratamento de exceções.
- Reutilização de código.
- Modularização.

## Objetivo educacional
Este projeto faz parte da minha jornada de aprendizado em Python e cibersegurança, com foco inicial em fundamentos de programação e segurança defensiva.
